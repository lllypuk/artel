## Логика приоритетов

1. **P (Проактивный агент)** — инфраструктура планировщика нужна для D, H, F. Начинать с него.
2. **D (Самодисциплина + OKR)** — ядро личного помощника, самый высокий impact.
3. **H (Здоровье и спорт)** — независимый инструмент, реализуется параллельно с K.
4. **K (База знаний)** — самый объёмный эпик, реализуется параллельно с H.
5. **G (Мониторинг сайтов)** — независимое дополнение, несложно.
6. **M (Автономная команда агентов)** — стратегический pivot: agent-shatrov как «тело» автономного
   агента, 2–3 инстанса с разными ролями (аналитик/разработчик/тестировщик) в общем Mattermost,
   координация без оркестратора. devbots — донор (MM-клиент, loop-detection), не фронт разработки.
7. **F (Финансы)** — разблокировать после перехода на Family-Finances-Service.
