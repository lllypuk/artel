# Эпик F: Финансы *(интеграция с Family-Finances-Service)*

Интеграция агента с сервисом учёта финансов через REST API.

**Статус:** 🔴 Заблокирован — ожидает перехода на Family-Finances-Service  
**Репозиторий сервиса:** https://github.com/lllypuk/Family-Finances-Service  
**Разблокируется:** когда сервис будет задеплоен и активно используется

---

## Задачи

- [ ] **F-1 Инструмент `finance`**  
  HTTP-клиент к REST API Family-Finances-Service. Авторизация (session token / API key).  
  Файлы: `internal/tools/finance.go`

- [ ] **F-2 Добавить транзакцию**  
  "Потратил 500р на еду" → агент определяет категорию, создаёт транзакцию через `POST /api/v1/transactions`.  
  LLM помогает с категоризацией из доступных категорий.

- [ ] **F-3 Запрос баланса и бюджетов**  
  "Сколько осталось на еду в этом месяце?" → запрос к `/api/v1/budgets`.  
  "Мой баланс" → сводка по счетам.

- [ ] **F-4 История расходов**  
  Поиск транзакций по категории, периоду, сумме.  
  "Сколько потратил на кафе за последний месяц?"

- [ ] **F-5 Финансовый срез в брифинге**  
  В утреннем брифинге (P-2): расходы вчера, остаток бюджета по ключевым категориям.

- [ ] **F-6 Бюджетные алерты**  
  Проактивно через P-1: "Ты потратил 80% бюджета на развлечения, осталось 5 дней до конца месяца".

- [ ] **F-7 Месячный финансовый отчёт**  
  Итоги месяца в еженедельном отчёте (P-4): топ категорий расходов, сравнение с прошлым месяцем.

---

## Конфигурация (пример)

```yaml
finance:
  enabled: false             # включить после перехода на сервис
  base_url: "https://budget.shatrov.tech"
  api_key: "..."             # или session-based auth
  timeout_seconds: 15
  currency: "RUB"
```

---

## Зависимости

- Требует: запущенный и используемый Family-Finances-Service
- Используется в: P-2 (утренний брифинг — F-5), P-4 (еженедельный отчёт — F-7)
- API документация: `GET https://budget.shatrov.tech/api/docs` (OpenAPI 3.0)
