# Historical and completed plans

This directory preserves completed Artel v2 plans and historical plans from the retired bot. They are evidence and history, not active product requirements or operational instructions. Do not rerun completed plans or execute retired bot/Docker commands against Artel v2.

Active plans remain in the parent `docs/plans/` directory. Immediately after a plan is completed, move it here and update all repository links, including relative links inside the moved file. Current developer guidance is in the root `AGENTS.md` and `docs/development.md`.
