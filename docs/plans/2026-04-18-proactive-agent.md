# Эпик P: Проактивный агент

Инфраструктура для всех проактивных сообщений агента.
Лимит: не более 7 сообщений в день, только в чётко заданное время.

**Статус:** 🟢 Готов к разработке  
**Приоритет:** 1 — инфраструктура для всех остальных эпиков

---

## Задачи

- [x] **P-1 Планировщик проактивных сообщений**  
  Новый механизм в агенте: расписание событий с временем отправки, счётчик сообщений за день (лимит 7), конфиг времён в `config.yaml`.  
  Файлы: `cmd/agent/proactive.go`, `internal/telegram/bot.go`

- [x] **P-2 Утренний брифинг**  
  В заданное время (напр. 08:00): погода на день, топ-цели из OKR, дайджест непрочитанных новостей, финансы вчера (когда F-эпик разблокируется).  
  Зависит от: P-1, D-5 (OKR), K-8 (дайджест)

- [x] **P-3 Вечерний чек-ин**  
  В заданное время (напр. 21:00): агент сам инициирует ревью дня — задаёт вопросы по шаблону: что планировал / что сделал / почему нет / оценка 1-10.  
  Зависит от: P-1, D-2 (ревью дня)

- [x] **P-4 Еженедельный отчёт**  
  Каждое воскресенье в заданное время: wins/fails недели, прогресс по OKR, статистика тренировок, финансовый срез (когда разблокируется).  
  Зависит от: P-1, D-3 (еженедельный ревью), H-2 (история тренировок)

- [ ] **P-5 Умные напоминания о целях**  
  Если цель (OKR / долгосрочная) не продвигается N дней — агент деликатно напоминает в допустимое время.  
  Зависит от: P-1, D-5 (OKR) — **реализовать после D-эпика**

---

## Конфигурация (пример)

```yaml
proactive:
  enabled: true
  max_messages_per_day: 7
  schedule:
    morning_briefing: "08:00"
    evening_checkin: "21:00"
    weekly_report: "sun 20:00"
    goal_reminder_days_idle: 3
```
