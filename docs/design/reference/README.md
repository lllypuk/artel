# Reference provenance

`canon-team-overview.html` and `canon-team-overview.png` are Artel's selected
static design sketch, authored in this repository on 2026-11-18 and rendered
with local headless Chromium at 1440×900. The owner selected `canon` from the
comparison. All labels, projects and status values are explicitly fictional.
No owner data, credentials, external assets or application screenshots are used.
HTML controls are inert; this is a composition reference for Qt, not a shipped
web UI, native acceptance evidence or a pixel-exact final visual contract.

The owner subsequently chose Zed Editor as the craft reference. Its screenshots
are not copied here or shipped with Artel. Public primary references:
- https://zed.dev/docs/appearance
- https://zed.dev/img/parallel-agents/sidebar.webp
- https://zed.dev/

Borrow UI hierarchy, density and finish, not code/editor/agent-execution features
or external image/icon/font assets. See the [design brief](../20261118-artel-desktop-brief.md).
