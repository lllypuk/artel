# Первый запуск Artel с Pi: согласованный сценарий

Целевой UX, а не описание текущей сборки. Не меняет объём приёмки этапа 5а.

- При первом запуске открывается постоянная вкладка «Помощник Artel». Через неё можно целиком настроить приложение разговором, не вводя команды в другом терминале. Помощник знает возможности этой сборки и опирается на фактическое состояние приложения.
- У проекта отдельная вкладка с рабочей сессией Pi в каталоге проекта. Используется обычный профиль владельца с его моделями и авторизацией, без копирования ключей в Artel.
- Вкладка возвращает в уже запущенную сессию. Для остановленной сессии предлагается «Продолжить последнюю сессию»; новую не создаём молча. Открытие вкладки ничего не отправляет в работу.
- В рабочей вкладке фраза «Возьми первую задачу из очереди» достаточна для старта: не нужны отдельные «Начать», повторная отправка или кнопка подтверждения. Artel показывает название выбранной задачи и переводит её в работу только после подтверждения от рабочего Pi, а не по факту отправки сообщения.
- Если модель не настроена, задача остаётся в очереди, причина видна в той же вкладке. При неизвестном исходе Artel не повторяет поручение автоматически.

## Фоновая работа и вехи задачи

- Явное поручение владельца может запустить Pi в фоне. Открытие карточки само по себе не запускает агента. «Открыть сессию» в карточке подключает терминал к живой сессии исполнителя именно этой задачи; закрытие терминала не прерывает работу. Если сессия остановлена, Artel показывает «Возобновить сессию» и ждёт действия владельца. agterm не обязателен.
- В карточке агент отмечает события «Взял задачу», «Нужен ответ», «Заблокирован», «Готово к проверке». Между ними он может оставить короткую свободную заметку о существенном результате. Запись ограничена порученной задачей. Чат, команды и вывод терминала в ленту не копируются. «Готово к проверке» не означает приёмку владельцем.
- Проверка: поручить задачу, открыть терминал из её карточки, закрыть его и дождаться следующей вехи. Повторное открытие должно показать ту же сессию без повторной отправки поручения.

Проверка сценария первого запуска: открыть Artel, попросить помощника открыть Stapel, увидеть рабочую сессию и дать одно поручение. Затем переоткрыть приложение и найти тот же разговор без дубликата сессии или задачи. Обычный терминал, agterm и ручной выбор runtime ID для этого пути не требуются.
